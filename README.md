# mvs-textbook

Online textbook of worked R examples for EDUS 663 (Applied Multivariate Statistics in Education), Virginia Commonwealth University. Built with [Quarto](https://quarto.org).

## Build

Open `mvs-textbook.Rproj` in RStudio and run `quarto render` from the Terminal (or the Render button on any chapter). The site is written to `docs/` for GitHub Pages.
